# M1（P0 最小闭环）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 PRD 第 12 章定义的 P0 闭环——教师创建房间并广播文本/文件，学员设昵称入班接收，15 秒 tips，列表查看、双击打开、一键复制、同名覆盖+1 份 .bak、Windows 服务自启。

**Architecture:** Cargo workspace 多 crate：纯逻辑层（protocol/store）零 IO 可单测；网络层（net）与角色层（host/agent）基于 tokio；GUI 与服务是两个独立进程（apps/），经 `ipc` crate 的命名管道通信。教师机即服务端（单 Host 多 Client），SQLite 索引 + 文件实体分目录落盘。

**Tech Stack:** Rust 1.100 (stable-msvc)、tokio、rusqlite (bundled)、serde/serde_json、uuid、sha2、windows-service、tauri 2.x；前端 React 18 + TypeScript + Vite 6 + pnpm。

**Spec:** [final_draft.md](../../final_draft.md)（PRD V1.0，唯一功能依据）；界面细节见 [ui-design.html](../../ui-design.html)。

## Global Constraints（所有任务隐含遵守）

- 平台 Windows 10/11 x64；MSVC 工具链；cargo 在 `$env:USERPROFILE\.cargo\bin`
- 单文件上限 100 MB、文本上限 10000 字、分块 1 MB（PRD 9.4）
- 风险类型默认拦截：`exe bat cmd com scr pif vbs js jar lnk`（PRD 5.3）
- 文件只落应用数据目录：`%APPDATA%\ClassShare\`（仓库根 `repo/`、索引 `index.db`、日志 `logs/`）
- 同名覆盖作用域键：`owner_id | audience | 文件名(或文本标题)`；`.part → SHA-256 → 原子替换 → 旧版转唯一 .bak → version+1`（PRD 5.7/7.3）
- 事件四类 `upsert/delete/rename/ack`，`event_id` 去重、`version` 判旧（PRD 3.6）
- 端口约定：UDP 发现 47820、TCP 服务 47821（PRD RK-07 由本计划确定）
- GUI 主色：教师蓝 `#2563EB`、学员青 `#0D9488`；正文 13–14px 微软雅黑；状态=文字标签+色块（PRD 4.6）
- 每个 cargo crate 都是 workspace 成员，根 `Cargo.toml` 统一 `[workspace.dependencies]` 版本
- 提交规范与流程见 [docs/DEVELOPMENT.md](../DEVELOPMENT.md)
