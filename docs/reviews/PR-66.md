## 1. 发现 1（阻塞）：注册表 command 的 `"%*"` 外层引号 → 多选 argv 合并为单参数

**实证（评审方 CommandLineToArgvW 三形态实测）**：

| 命令行形态 | 解析结果 |
| --- | --- |
| `"exe" ""C:\a.txt""`（%* 单文件展开） | argv[1]=`C:\a.txt` ✓ |
| `"exe" ""C:\a.txt" "C:\b.txt""`（**%* 多文件展开，当前实现**） | **argv[1]=`C:\a.txt C:\b.txt`（合并成一个参数）** ✗ |
| `"exe" "C:\a.txt" "C:\b.txt"`（去掉 %* 外层引号） | argv[1]/argv[2] 两参数 ✓ |

**后果链**：`file_args()` 对合并串 `Path::is_file()` → false → files/dirs 均空 → `share_files_from_argv` 两个 `if` 均不成立 → **多选右键静默无任何动作**（连 toast 都没有）。单文件右键正常（解释了 dev 初测为何以为通过）。

**根因与修复**：`scripts/register-context-menu.ps1` 的 `$cmd = "`"$exe`" `"%*`""` → 改为 `"`"$exe`" %*"`（一行）。Windows shell 对 `%*` 逐参数带引号展开，任何外层再包引号的写法都会塌缩为单参数。

**为何 SMOKE 实测未抓到**：「第二次以 `classroom-gui.exe <文件1> <文件2>` 启动（模拟资源管理器右键多选调起）」——直接以两个独立 argv 启动，**绕过注册表 `%*` 展开这一真实入口形态**。这是「测试形态 ≠ 真实入口形态」第 4 次同型变体（E3 桩 → PR-34 §9.2 → t9 mock → 本项）。建议修复后补**经注册表真实 command** 的实测（或 `cmd /c` 复现 %* 展开）。

## 2. 发现 2（一般）：TipsStack toast 窗高 effect 依赖数组缺 `toasts.length`
`useEffect(..., [cards.length, overflowCount])` 内计算含 `+ toasts.length * (GAP + 36)`——依赖缺失：**无 tips 卡片时首次 toast 到达，窗高 effect 不重跑** → 窗高保持旧值 → toast 可能被裁剪不可见（拖放/粘贴结果提示的主要使用场景）。修复：deps 加 `toasts.length`。次要：`queue.length===0 → tips_dismissed` 只按 queue，toast 消失后窗口不隐藏（可接受）。
