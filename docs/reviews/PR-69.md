## 2. 发现问题

### 发现 1（一般，但会阻断 TC-01 验收）：`room_filter` 取值源与验收安装命令不一致

链路：svc `room_filter: Some(cfg.room_code)` ← 学员机 svc.json `room_code` ← install.ps1 `-Room`（**默认 'XK-204'**）。而验收方案 §3.4 / 附录 A 的**学员安装命令不传 `-Room`**（`install.ps1 -Mode student -Nickname alice -GuiExe …`），教师命令写 `-Room <房间码>`（QA 可变）。
后果：若 QA 给教师指定非 XK-204 房间码，学员机 filter 仍为默认 XK-204 → 所有信标被过滤 → **自动发现永久失败 → TC-01 主判据失败**。非代码 bug（策略正确），是配置口径缺口。
建议（推荐 a，零代码）：**a** 验收方案学员命令补 `-Room <与教师完全相同房间码>` + install.ps1 学员摘要行提示；**b**（更贴 PRD「学生不知房间码」）install.ps1 学员未传 `-Room` 时写空串 → svc 映射 `room_filter=None`（连首个），仅显式传才精确过滤（serde 侧空串判断，小改不动类型）。
