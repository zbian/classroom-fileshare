- [x] **15s 自动消失**：`TOTAL_MS = 15_000`，倒计时仅作用于显示中的前 3 条 ✓

- [x] **≤3 条堆叠 + 「还有 N 条」**：完整队列内存态、窗内恰 3 卡 + 琥珀色合并行（连发 5 条实测：3 卡 + 「还有 2 条」）；窗高随堆叠数 `update_tips_height` 同步，命中区=可见区 ✓

## 3. 过程中发现并修复的缺陷：gui.json BOM 静默丢失

**真实缺陷**：Windows 记事本 / PowerShell 5.1 写出的 JSON 带 UTF-8 BOM，`serde_json` 拒绝前导 BOM → 配置解析失败 → 图标位置**静默**回退默认位（无报错，难排查）。修复：`GuiConfig::load` 剥离 `\u{feff}` 后解析（state.rs:48 含注释说明）；实测复现 → 修复 → 位置恢复正常。

轻微建议（不阻塞）：补 BOM 剥离的单测用例（紧邻 state.rs 既有配置测试），防止回归。
