## 4. 发现问题（均非阻塞）

### 发现 1（一般）：B1 自动发现房间列表为 mock 常量，Discovered 未接线
NicknameDialog 的 `DISCOVERED = [{room:'XK-204',…}]` 为硬编码（自注释「T7 Discovered 接线后替换」），而描述「自动发现房间列表（Discovered 接线）」——T7/#38 已合入且 Rust retag 已支持 Discovered（`{t:Discovered,beacons}`），接线成本仅为 store 消费 beacons → B1 列表。建议随包接线，或如实改为「mock 房间列表，Discovered 接线随真实链路」。

### 发现 2（一般）：「昵称持久化 + 重启不再弹 [x]」与实现不符
`nicknameDone` 为内存态且 store.init 对 student 无条件重开 B1——**重启复弹**；gui.json 无 nickname/done 持久化字段。验收对照该项标 [x] 不准确。建议：gui.json 增持久化标志（Rust state 一行 + init 读取）或如实改为「随真实 SetNickname 链路（TC-01 双机）」——与已声明延后口径对齐。

### 发现 3（轻微）：学员侧 M2 能力暴露未对齐教师侧占位规范
学员 D2 工具栏「+粘贴文本/删除」在服务端 M1 明确拒绝（「学员回传/删除在 M2 提供」）、Footer「直接共享给教师」邀请文案超前（PRD 6.8 待发队列 M2）——教师侧同类占位均 disabled+title 归属，学员侧未对齐；建议禁用态+「M2」标注。连带：DeleteConfirmDialog 对学员删除自己内容场景文案未适配（现「所有学员端同步移除」，M2 学员语义应为「同步到教师端」）——M2 语义项，随 M2 修正。

### 发现 4（nit）：D1 stateChip default 分支 label 直接显示英文枚举
非新/已下载/下载中 的异常态（如 DeleteDeferred）会以英文枚举原文上屏；建议映射中文或过滤。
